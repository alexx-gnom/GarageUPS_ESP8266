# Garage UPS Controller

Контролер резервного живлення для майстерні на ESP8266 Witty.

## Hardware

- ESP8266 Witty (ESP-12F)
- ADS1115, живлення 3.3 V
- ACS712-30A
- NTC 10k
- DS18B20
- Акумулятор WESTA EFB 78Ah 12 V

## GPIO

| GPIO | Призначення |
| GPIO4 | I2C SDA |
| GPIO5 | I2C SCL |
| GPIO12 | Захисне реле |
| GPIO13 | DS18B20 |
| GPIO14 | Канал навантаження 0 |
| GPIO16 | Канал навантаження 1 |

## ADS1115

| Канал | Призначення | Дільник |
| A0 | NTC | NTC / 11 kΩ |
| A1 | Живлення зарядки | 100 kΩ / 11 kΩ |
| A2 | Напруга акумулятора | 100 kΩ / 11 kΩ |
| A3 | ACS712 | 9.889 kΩ / 3.3 kΩ |

ADS1115 працює від 3.3 V, режим вимірювання GAIN_ONE.

### Напруга акумулятора

- Верхній резистор: 100 kΩ
- Нижній резистор: 11 kΩ

### ACS712

- Нуль на вході ADS1115: 0.6320 V
- Чутливість після дільника: 0.01497 V/A
- Значення перевірені на навантаженні приблизно 0.2–2.2 A.

### NTC

- Нижній резистор: 11 kΩ
- Номінальний опір: 10 kΩ при 25 °C
- Початковий Beta: 3950
- Температуру порівнюємо з DS18B20.

## Програмна структура

- `garage_ups_8266.ino` — головна логіка.
- `config.h` — GPIO та параметри.
- `secrets.h` — локальні Wi-Fi облікові дані.
- `sensors.h/.cpp` — вимірювання та калібрування.
- `outputs.h/.cpp` — вихідні канали.
- `web.h/.cpp` — HTTP-сервер та API.
- `web_page.h` — HTML, CSS та JavaScript.

## Безпека

- Зарядний пристрій працює автономно; ESP8266 не замінює його штатну логіку.
- Апаратний термостат залишається незалежним від контролера.
- Програмний захист не повинен бути єдиним засобом аварійного відключення.
